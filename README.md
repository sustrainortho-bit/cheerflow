# CheerFlow

チアリーディングのフォーメーション（隊形）・構成を作るためのエディタアプリ。メンバー配置、スタント（トス技）のロール管理、音楽同期、プレゼンモードまでを1つの画面で作れる。Googleアカウントでログインすると、プロジェクトをアカウントに保存し、メンバーを招待して共有・共同編集できる。

公開URL: https://cheerflow-app.web.app/

詳細・引き継ぎ方法は [CLAUDE.md](CLAUDE.md) を参照。

元々は別のClaude.aiチャット上でArtifact（単体HTML）として開発されていたものを、2026-08-31にこちらのプロジェクト体系に引き継いだ。
